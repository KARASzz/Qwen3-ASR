# Qwen3-ASR 远程转写

双击 `控制台.command`，选择 `1` 生成 TXT 文稿，选择 `2` 生成 SRT 字幕。把待处理音视频放进本目录的 `输入` 文件夹；结果会保存到 `输出` 下的独立批次目录。选择 `5` 可只检查远端连接与运行环境。

模型在 `169.254.88.88` 的 `KARASs-Mac-mini-BG.local` 上执行。本机只运行轻量的 SSH 文件传输与任务客户端，不加载转写模型。SSH 连接已使用本项目专用密钥配置，密码不保存在项目中。

文件共享地址为 `smb://169.254.88.88`。SMB 用于访问共享文件；任务通过 SSH 在远端 Mac 上执行。远端项目位于 `/Volumes/Sea of Symbols/Qwen3-ASR-本地语音识别`。远端需要保持开机，网络需要能访问该地址。

远端配置在 `remote-config.json`。远端连接、上传、转写或结果取回失败时会报告错误，并保留已有文件供排查，不会回退到本机运行模型。旧的本机入口备份为 `控制台.command.本机推理已停用.bak`，不可执行。

本机 `.remote-ssh/` 中的私钥不得分享或提交；远端只安装了对应公钥，且禁用了该密钥的终端、端口转发和代理转发能力。
